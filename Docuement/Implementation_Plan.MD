| `--color-white` | #FFFFFF | Body background, cards |
| `--color-gray` | #666666 | Secondary text, inactive menu tabs |

### 3.2 Typography
- **Font Family**: Montserrat or Poppins (Google Fonts)
- **Weights**: 400 (Regular), 600 (Semi-Bold), 700 (Bold), 800 (Extra-Bold)
- **Scale**:
  - Hero Heading: 48-64px, Bold, Uppercase
  - Section Titles: 28-36px, Bold, Title Case
  - Subheadings: 20-24px, Semi-Bold
  - Body: 16px, Regular, high line-height (1.6-1.8)
  - Small/Label: 14px, Medium Gray

## 5. Technical Implementation Notes

### 5.1 Tech Stack (Recommended)
- **Framework**: React + Next.js (or plain HTML/CSS/JS if simpler)
- **Styling**: Tailwind CSS (for consistent theme tokens)
- **Icons**: Lucide or Heroicons (line-art style)
- **Animations**: Framer Motion or AOS for scroll-triggered reveals
- **Form**: Formspree or EmailJS for contact form
- **Map**: Google Maps Embed API
- **Hosting**: Vercel / Netlify

### 5.2 Responsive Breakpoints
- Mobile: 320px - 767px
- Tablet: 768px - 1023px
- Desktop: 1024px+

### 5.3 Performance Considerations
- Lazy-load images
- Optimize hero images (WebP format)
- Minimize third-party scripts
- Font subsetting for Montserrat/Poppins

### 5.4 SEO
- Meta titles & descriptions per page
- Open Graph tags for sharing
- Alt text on all images
- Semantic HTML structure (h1-h6, sections, article)
- Sitemap.xml
